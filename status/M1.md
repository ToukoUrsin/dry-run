## Prompt 021 reference expert — held-out loose result

The slow experimental expert was replaced by the measured reference cycle in
`dryrun/expert.py`. It uses a scratch `MjData` for IK, minimum-jerk actuator
targets, the measured presentation poses, ground-truth labels when no
inspector is supplied, and a `done` phase. The inspection mount is outside the
brick work area with collision disabled; the episode limit is
`(120 + 330 * brick_count)` ticks for loose and doubled for retry tiers. The
result score is correct bowl placement by defect label, with false accepts and
false rejects reported separately.

```text

  .venv/bin/python -u /tmp/bench_ref.py

```
