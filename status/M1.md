# M1 — open

The rollout API is published and the real SO-101 station loads in MuJoCo 4.0.1. The isolated friction grasp now reaches the ten-trial gate, but the loose-tier expert is not sorted reliably and the messy/pile tiers are unrun at the new tier split. No completion claim is made.

Current proofs:

```text
uv run python -c 'import mujoco; print(mujoco.__version__)' -> 4.0.1
uv run python -m dryrun.mjcf_station check assets/station.xml -> loaded=true, brick_count=5, intersections=[], bowl_overlap=[], cameras pass=true
MUJOCO_GL=egl uv run python -m dryrun.grasp_test --out /bulk2/runs/dryrun/m1/grasp_stiff2.jsonl --xml /bulk2/runs/dryrun/m1/grasp_stiff2.xml -> 10 trials, 10 lifted, 10 both-pad contacts; peak pad force recorded per trial
nice -n 10 env MUJOCO_GL=egl uv run python -m dryrun.benchmark --tier loose --seeds 5 --without-inspector --output /bulk3/runs/dryrun/loose5d.json -> 1/5 bricks sorted, score 0.2, 1 contact pickup
MUJOCO_GL=egl uv run python - <<'PY' ... StationEnv.reset()/step() ... PY -> top/inspection uint8[64,64,3], joints float32[6], public clock 30 Hz
```

The held-out partition is fixed as loose 80 seeds, messy 70 seeds and pile 50 seeds in `dryrun/benchmark.py`; the full run remains open until it has run. The page contract for per-seed scene values, thumbnails and replay rows is in `docs/interfaces.md`.
