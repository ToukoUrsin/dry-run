# M2 — open

M2 remains open. The withdrawn first attempt is retained as a measured failure:
AUROC 0.5700, false rejects 59.75%, false accepts 29.72%. Its 128 px training
view put the brick at roughly 20 px, and the rollout camera was a different
distribution; those numbers are not a benchmark claim.

The rebuild uses one shared 384×384 inspection path. The present pose is
`[0.28, 0.00, 0.16]` m; the camera is `[0.28, -0.10, 0.23]` m (12.2 cm,
34° FOV). The judged face is the visible studded top face. Stud defects have a visible dark cavity/chip mark in the generated top-face render while retaining their physical missing/reduced geometry. The crop hides arm,
bowls and camera hardware while preserving the real physics pose. Underside
marks are not claimed visible.

## Rebuild data

Dataset: `/bulk3/runs/dryrun/m2_rebuild/data`.

- 1,600 good training renders
- 400 good validation renders plus 100 each of seen scribble, dot, sticker and discolouring defects
- 2,200 test renders: 400 good and 300 of each of six defect types
- `chipped_stud` and `missing_stud` are held out from training and threshold selection

The threshold is selected on validation only. The renders and rollout frames
come from `render_inspection`/`render_inspection_frame`; contact samples were
visually checked at `/bulk3/runs/dryrun/m2_rebuild/shot_*.png` and
`/bulk2/runs/dryrun/shot_rebuild/`.

The pre-visibility-fix PatchCore run reached validation AUROC 0.98955 but failed
held-out stud recall (3.0% chipped, 17.3% missing); it is retained as failure
evidence. The selected final model is the wide-ResNet-50 PatchCore export at
`/bulk3/runs/dryrun/m2_rebuild/final_model/`, trained on 1,600 good
`data_v1_subtle` frames and evaluated on the current post-mark v2 set. Its
provenance is in `/bulk3/runs/dryrun/m2_rebuild/final_model_manifest.json`.

The exact evaluation is
`/bulk3/runs/dryrun/m2_rebuild/final_model/evaluation.json`; the source
comparison is `eval_v1_model_on_v2/patchcore_v1_subtle_evaluation.json`. The
source command was:

```text
.venv/bin/python -m dryrun.inspector_eval --model /bulk3/runs/dryrun/m2_rebuild/models_v1_subtle/PatchCore/openvino/weights/openvino/dryrun_inspector_patchcore.xml --data /bulk3/runs/dryrun/m2_rebuild/data --out /bulk3/runs/dryrun/m2_rebuild/eval_v1_model_on_v2/patchcore_v1_subtle_evaluation.json
```

At commit `2dc3b59`, validation AUROC is `0.97175625` with threshold
`0.6663667559623718`; test AUROC is `0.9766986111`, false rejects are `3.25%`,
and false accepts are `8.333%` on 2,200 test frames. Held-out recalls are
`0.87` (chipped stud) and `0.9866667` (missing stud). CPU timings are in
`/bulk3/runs/dryrun/m2_rebuild/final_model/latency.json`: batch-2 median
`522.64 ms` at one thread and `212.90 ms` at four threads, or `261.32` and
`106.45 ms` per frame. PaDiM, the 15-vector PatchCore and pixel baseline
comparisons remain under `eval/`; the EfficientAD-S attempt is recorded as
aborted for excessive CPU time.

## In-loop and page obligations

The required in-loop run used the real seeded multi-brick API and the selected
model:

```text
100 seeded loose rollouts via dryrun.rollout.run(seed, "expert", inspector=Inspector(final_model), tier="loose") after active-body crop and valid-presentation gate
```

The artifact is `/bulk3/runs/dryrun/m2_rebuild/rollout_confusion_100_final.json`,
produced at commit `2dc3b59`. It contains 100 rollouts, 13 valid present
verdicts and 23 explicit `inspection_invalid` events. The valid-present table is
`TP=4, TN=1, FP=8, FN=0`: false rejects `88.89%`, false accepts `0%`. The
remaining cycles failed to pick, lift or hold the brick at the presentation
pose. This is failure evidence and keeps M2 open; no synthetic or slipped-table
frame is counted as a verdict.

The Modal draw boundary and page projection are implemented and smoke-tested:
warm inspection is under 2 seconds and returns rendered RGB, heatmap, score,
threshold, verdict and latency. The Sunday `inspect_photo` command now accepts
and records an explicit `X Y W H` crop around the visible top face.

Validation commands include:

```text
python -m compileall -q dryrun tests web
MUJOCO_GL=egl PYTHONPATH=. uv run python -c "from dryrun.rollout import run; print(run(0, 'expert', tier='loose')['score'])"
```

This status remains open because the valid-present rollout confusion misses the
operational target and the expert does not yet hold enough seeded bricks at the
inspection pose. Every future number must name its command, artifact path and
commit. The withdrawn fixed one-brick loose tier is excluded from training and
benchmark claims.
