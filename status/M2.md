# M2 — open

Standalone proof exists for Anomalib/PaDiM good-only training, OpenVINO export, a 580-image confusion evaluation with held-out defect types, and CPU timing. The milestone remains open because the real MuJoCo benchmark is not yet wired to use this inspector to decide bowls.

Evidence: `uv run python -m dryrun.inspector_train` produced `/bulk2/runs/dryrun/m2/model/Padim/dryrun_bricks/v1/weights/lightning/model.ckpt` and `/bulk2/runs/dryrun/m2/model/openvino/weights/openvino/dryrun_inspector.xml`; evaluation JSON is `/bulk2/runs/dryrun/m2/evaluation.json` (580 images, mean 8.33 ms, p95 15.10 ms). Exact benchmark integration is still required.
