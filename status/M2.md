# M2 — complete

The inspector is a good-only Anomalib PaDiM model exported to OpenVINO and
called by the MuJoCo rollout at `present`. The one-seed integration smoke test
passed; the main session owns the full held-out benchmark sweep.

## Dataset provenance

These are seeded MuJoCo renders from the SO-101 station inspection camera, not
phone photographs or a clean-brick-only camera dataset. The brick is in the
gripper envelope, with seeded pose, camera and light jitter. The manifest is
`/bulk2/runs/dryrun/m2/data/manifest.jsonl` and generated assets are in
`/bulk2/runs/dryrun/m2/data/assets/`.

| split | contents | count |
|---|---|---:|
| train | good bricks only | 128 |
| validation | 160 good + 50 each of scribble, dot, sticker and discolouring | 360 |
| test | 400 good + 300 each of six defect types | 2,200 |

The threshold was selected on validation only. `chipped_stud` and
`missing_stud` were held out from both training and threshold selection.

## Training, comparison and deployment

The PaDiM artifact is
`/bulk2/runs/dryrun/m2/model/openvino/weights/openvino/dryrun_inspector.xml`;
its checkpoint is
`/bulk2/runs/dryrun/m2/model/Padim/dryrun_bricks/v4/weights/lightning/model.ckpt`.
The final comparison is `/bulk2/runs/dryrun/m2/model/model_comparison.json`.
All three models used the same good-only train/validation data and exported
successfully through Anomalib 2.7.0:

| model | validation image AUROC | OpenVINO CPU median / p95 (1 thread) | median / p95 (4 threads) |
|---|---:|---:|---:|
| PaDiM | 0.6371 | 35.24 / 57.55 ms | 29.84 / 187.53 ms |
| PatchCore | 0.7064 | 114.81 / 432.85 ms | 47.55 / 113.22 ms |
| EfficientAD | 0.5520 | 763.08 / 831.31 ms | 251.59 / 293.39 ms |

PaDiM is the deployed choice because its CPU path is substantially faster than
PatchCore and EfficientAD for the station's per-brick decision, while the
comparison AUROC and held-out test results remain visible above and below.

## Held-out test result

Command:

```text
MUJOCO_GL=egl nice -n 10 uv run python -m dryrun.inspector_eval
```

Output is `/bulk2/runs/dryrun/m2/evaluation.json`. It reports AUROC 0.5700,
threshold 0.6907514334, and this 2,200-image confusion table:

| actual / decision | count |
|---|---:|
| TP (defect → defective) | 1,265 |
| TN (good → good) | 161 |
| FP (good → defective) | 239 |
| FN (defect → good) | 535 |

Operationally, false accept is a defective frame accepted as good:
`FAR = FN/(TP+FN) = 535/1800 = 0.2972`. False reject is a good frame sent
to the defect bowl: `FRR = FP/(TN+FP) = 239/400 = 0.5975`. The same artifact
also gives the conventional aliases `FNR = 0.2972` and `FPR = 0.5975`.

| defect type | test n | recall |
|---|---:|---:|
| scribble | 300 | 0.6633 |
| dot | 300 | 0.6267 |
| sticker | 300 | 0.9300 |
| chipped_stud (held out) | 300 | 0.5867 |
| missing_stud (held out) | 300 | 0.6500 |
| discolouring | 300 | 0.7600 |

The model misses many small scribbles and dots and some stud geometry. The
station camera can only score what is visible on the presented face; hidden
side defects are not observable, so a future policy that needs that guarantee
must turn the brick and inspect again.

For the deployed PaDiM model, the final OpenVINO timing from the same command
was 29.19 ms median / 81.74 ms p95 at one thread and 36.58 ms median / 55.40
ms p95 at four threads (100 timed inferences after 20 warmups). The four-thread
run is slower on this busy box; that is the measured result.

## Interface smoke test

```text
MUJOCO_GL=egl uv run python - <<'PY'
from dryrun.defects import render_inspection, render_drawing_frame
from dryrun.inspector import Inspector
import numpy as np
frame = render_inspection(123, 'none')
out = Inspector(threads=1)(frame)
drawn = render_drawing_frame(np.full((12,12,4), [255,0,255,255], dtype=np.uint8), seed=123)
print({'frame': frame.shape, 'verdict': out['verdict'],
       'score': round(out['score'], 6), 'threshold': round(out['threshold'], 6),
       'heatmap': (out['heatmap'].shape, str(out['heatmap'].dtype)),
       'drawing_frame': drawn.shape})
PY
```

Output: `frame=(128, 128, 3)`, `verdict=defective`, `score=1.0`,
`threshold=0.690751`, `heatmap=((128, 128), uint8)`, and
`drawing_frame=(128, 128, 3)`.

The rollout integration smoke artifact is
`/bulk3/runs/dryrun/m2/benchmark_smoke.json`: one loose seed, one brick, one
contact pickup, one verdict, one success and score 1.0.

Numbers above were generated from the inspector artifacts with source commit
`817de72087be6cf97ca4a9a985d90c48014303ee`; the dataset and model binaries
remain in `/bulk2/runs/dryrun/m2/` and are named explicitly above.
