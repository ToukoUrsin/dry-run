# M2 — inspector in the loop

The inspector is a good-only anomaly detector (`dryrun.pipeline.inspect`). It consumes
the rendered brick observation and never reads simulator labels at evaluation time.
The 200-seed benchmark command records false accepts and false rejects in its output and
the telemetry table. The current deterministic smoke run reports 0/0; full Anomalib and
OpenVINO training is optional when those packages are installed.

Evidence command: `python -m dryrun benchmark --seeds 200 --db /tmp/dryrun.sqlite`.
