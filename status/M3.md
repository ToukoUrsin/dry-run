# M3 — complete for the telemetry and deployment gates; Tiger-backed page is live

The local writer now records every replay sample at the page contract (30 Hz pose/joint rows, event rows, and one outcome row). `sync` copies complete rollouts to Tiger Cloud by rollout id and is safe to run twice. The schema is shared by the local TimescaleDB container and Tiger Cloud; the raw hypertable is compressed and has a ten-minute compression policy. The dashboard API reads `rollout_1s` and `benchmark_checkpoint`, never the raw rows.

Source commit used for the measurements below: `ff3d3bf` (`document telemetry sync and final page proof`).
