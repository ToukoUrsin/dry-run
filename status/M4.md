# M4 — open

The milestone remains open because the learned policy has not yet been wired into the held-out physics benchmark. The underlying dataset/checkpoint artifacts are rerunnable, but the current dataset trajectory is a generated MuJoCo camera/state trace rather than successful expert demonstrations;

```text
MUJOCO_GL=egl .venv/bin/python dryrun/make_dataset.py -> /bulk2/runs/dryrun/m4/lerobot-dataset, 4 episodes, 240 frames
.venv/bin/python -m dryrun.check_lerobot -> frames=240, episodes=4, MuJoCo camera/state/action features
OMP_NUM_THREADS=8 .venv/bin/python -m dryrun.train_policy -> loss 0.0130382036 (epoch 1) -> 0.0009885098 (epoch 40), policy.pt
```

The model consumes rendered images and six joint states; no simulator labels are passed to it. A first one-seed physics comparison now runs through `dryrun.policy_benchmark`:

```text
MUJOCO_GL=egl .venv/bin/python -m dryrun.policy_benchmark --seeds 1
-> learned policy: seed 0, 1/9, score 0.1111111
uv run python -m dryrun.render --seed 0 ...
-> scripted expert: seed 0, 0/9, score 0.0
```

The learned-policy result is exploratory and not a held-out 200-seed claim; that benchmark remains open.
