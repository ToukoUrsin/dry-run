# M5 — Nemotron failure analyst

`nemotron_analyse` calls `nvidia/nemotron-3.5-super-vl-120b-a12b` through the documented
OpenAI-compatible endpoint when `NVIDIA_API_KEY` is present. It enforces a small JSON
schema (`reason`, `scenes`) and falls back to a deterministic result when offline. This
keeps benchmark runs reproducible; API runs should be recorded as JSONL under
`/bulk2/runs/dryrun/`.

Evidence: `python -m dryrun nemotron --seed 17`.
