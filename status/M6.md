## Connected evidence

`/api/score` and `/api/telemetry` read Tiger aggregates and expose raw row
count, aggregate query timing, compression state/ratio, cycle time, drops,
false accepts and false rejects. `/api/inspector` supplies the measured
confusion matrix, defect recalls and CPU latency. `/api/replays/7`, both video
endpoints, and `/so101.glb` return HTTP 200. The custom-defect endpoint remains
wired to the deployed Modal worker; when no worker response exists, the page
says so instead of inventing a verdict.
